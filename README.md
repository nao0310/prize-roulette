# 景品ルーレット

1〜N番の参加番号からルーレットで景品の当選番号を抽選する、ブラウザだけで動くページです。

- 公開ページ: https://nao0310.github.io/prize-roulette/
- サーバー不要・無料。`index.html` をダウンロードしてダブルクリックすれば、ネットがなくても動きます。

## 使い方
1. 「参加人数」を入れる
2. 景品リストのExcel（A列=順位、B列=景品名）を「Excelを読み込む」で読み込む（例: `sample-prizes.xlsx`）
3. 「発表モード」で全画面にして、SPINで下位から順に抽選
4. 当選者がいないときは「当選者がいないので回し直す」、最後にリザルトを表示

## データの扱い
- 読み込んだExcelや抽選結果は、開いたPCのブラウザの中だけに保存されます。どこにも送信されません。
- 乱数はブラウザの暗号用乱数（`crypto.getRandomValues`）を使っています。
