# 景品ルーレット

1〜N番の参加番号からルーレットで景品の当選番号を抽選する、ブラウザだけで動くページです。

- 公開ページ: https://nao0310.github.io/prize-roulette/
- サーバー不要・無料。`index.html` をダウンロードしてダブルクリックすれば、ネットがなくても動きます。
- スマホ（縦向き・横向き）、タブレット、PCに対応。スマホでは「ホーム画面に追加」でアプリのように使えます。

## 使い方

1. **参加人数**を入れる（2〜500人）。ルーレットは 1〜参加人数 の番号になります
2. **景品リスト**のExcel / CSV を「Excelを読み込む」で読み込む（例: [`sample-prizes.xlsx`](sample-prizes.xlsx)）
   - 見出しに「順位」「景品名」があればその列を、なければ A列=順位、B列=景品名 として読みます
   - 読み込まなければダミーの景品20件で動きます
3. （任意）**名簿**の CSV を「名簿を読み込む（任意）」で読み込む（例: [`sample-roster.csv`](sample-roster.csv)）
4. 「**発表モード**」で全画面にして、SPIN で抽選（基本は下位から順に、最後が1位）
5. 当選者がいないときは「**当選者がいないので回し直す**」（あとから一覧の番号ボールを押しても回し直せます）
6. 最後に **リザルト**（結果一覧）が表示されます

## 機能一覧

| 機能 | 内容 |
|---|---|
| 抽選 | 1〜参加人数の番号から、重複なしで抽選。順位ごとに演出の長さが変わります（下位は短め、1位はじっくり） |
| 抽選の順番 | 「順番：下位から」（基本）／「順番：1位から」を切り替え可能（抽選前のみ） |
| 回し直し | 当選者がいない番号を外して、同じ景品をもう一度抽選。外した番号は以後出ません |
| 名簿（任意） | 番号と名前のCSVを読み込むと、当選番号に名前を添えて表示します（下記） |
| 発表モード | 全画面にして、設定用のボタンを隠します。Escキーで全画面を解除すると元に戻ります |
| リザルト | 全景品の当選番号（と名前）を一覧表示。右上の「結果を見る」から何度でも開けます |
| 途中保存 | ページを閉じたり再読み込みしても、抽選の途中経過は残ります（そのPC・そのブラウザのみ） |
| リセット | 当選番号・外した番号を消して最初から。景品リストと名簿は残ります |
| 音 | 回転に合わせたドラムロールと当選ファンファーレ。右上で音あり／なしを切り替え |

## 名簿機能（任意）

名簿を読み込まなければ、これまでどおり番号だけで動きます。

- **抽選は番号だけで行います。** 名前は当選した番号の横に表示するためだけに使い、抽選の結果には一切影響しません
- 形式: CSV（UTF-8 / Excelで保存したShift_JIS のどちらも可）または .xlsx
  - 見出しに「番号」「名前」（「氏名」「参加番号」なども可）があればその列を、なければ A列=番号、B列=名前 として読みます
  - `001` のような先頭が0の番号も読めます。同じ番号が複数ある場合は後の行を使います
- **参加人数は名簿に合わせます。** 名簿を読み込むと、参加人数（ルーレットの番号の範囲）が名簿の人数（名簿にある最大の番号）に自動で変わり、名簿を外すまで手では変えられなくなります
  - 番号に抜けがある名簿（例: 1〜40番のうち5人分がない）の場合は、ルーレットは1〜40番のままで、名前のない番号があることを画面でお知らせします
  - 抽選の途中で名簿を読み込んだときは、途中経過を壊さないよう参加人数はそのままにし、リセットしたときに名簿の人数に合わせます
- 名前は、当選画面・景品一覧・回し直しの確認・リザルトに「〇〇 さん」と表示されます
- 抽選の途中で読み込んでも、すでに出た番号に名前が付きます
- 「**名簿を外す**」で、画面からもこの端末からも名簿を削除します

```csv
番号,名前
1,ゲスト001
2,ゲスト002
```

## セキュリティとデータの扱い

**読み込んだファイル（景品リスト・名簿）や抽選結果が外部に送られることはありません。**

- **通信を一切しない作りです**
  - ページに必要なもの（Excel読み込み用のプログラム、フォント、アイコン）はすべて同梱しており、外部のサーバーから何も読み込みません
  - さらにブラウザのセキュリティ機能（Content Security Policy）で、このページからインターネットへの通信そのものを禁止しています（`connect-src 'none'` など）。万一プログラムに不具合があっても、データを外に送ることはできません
- **ファイルはブラウザの中で読むだけです**
  - 選んだExcel / CSV は、開いている端末のブラウザの中で読み取り、GitHubやほかのサーバーにはアップロードされません
- **保存場所は、その端末のブラウザの中だけです**
  - 景品リスト・名簿・抽選の途中経過は、ブラウザの保存領域（localStorage）に保存されます。ほかの端末や、ほかの人には共有されません
  - 名簿を消したいときは「名簿を外す」、すべて消したいときはブラウザの「サイトデータの削除」を使ってください
  - 共用のPCで使ったあとは、「名簿を外す」で名簿を消しておくと安心です
- **名前などに記号やタグが入っていても**、文字としてそのまま表示し、プログラムとして実行されることはありません
- **乱数**はブラウザの暗号用乱数（`crypto.getRandomValues`）を使っています。演出の長さや止まり方は当選番号が決まったあとに計算するだけで、当たりやすさに影響しません
- このリポジトリに入っているのは、ページ本体と架空のサンプルデータだけです。**実際の名簿や景品リストはリポジトリに入れないでください**（公開リポジトリは誰でも見られます）

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ページ本体（これだけで動きます） |
| `sample-prizes.xlsx` | 景品リストのサンプル（ダミー） |
| `sample-roster.csv` | 名簿のサンプル（架空の名前） |
| `favicon.svg` ほか `*.png` | アイコン |
| `manifest.webmanifest` | スマホの「ホーム画面に追加」用の設定 |
